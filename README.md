# Steadcore Home Improvements

Static marketing website for Steadcore Home Improvements, with a clean blue theme and subtle animations.

The landing page has a tile for each service, each linking to its own mini-site:

- `/water` (plumbing, leak detection, damp and environmental surveys)
- `/bathrooms` (full installations, toilets, baths, basins, showers, tiling)
- `/security` (alarms, sensors, CCTV)
- `/entertainment` (home cinema, entertainment systems)
- `/handyman` (handyman and home improvements: general repairs, decorating, carpentry, tiling, window replacements, cleaning and garden maintenance; `/maintenance` and `/general` redirect here)
- `/kitchens` (kitchen installations)
- `/roofing` (repairs, replacements, maintenance)

## SEO

- Every page has its own title, description, canonical URL, Open Graph tags and JSON-LD structured data.
- `/areas/` and the pages under it target the two-hour radius around Bournemouth. They are generated by `node build-areas.js`, which also writes `sitemap.xml` and `robots.txt`. Edit the `places` list in that file and re-run it to add or change areas.
- The site uses `https://www.steadcorehomeimprovements.co.uk` in its canonical URLs, structured data, sitemap and robots file.

## Run locally

Run `npx serve .` and open the printed address so the `/water`-style paths work.

The contact form posts to Web3Forms and delivers enquiries to `steadcore@gmail.com`. To activate it:

1. Go to https://web3forms.com, enter `steadcore@gmail.com` and get a free access key.
2. Replace `YOUR_WEB3FORMS_ACCESS_KEY` in `index.html` with the key.
3. Check your inbox for the Web3Forms verification email and confirm it.

Until the key is added, submissions will fail and the form shows the phone number as a fallback.
